# API types

`generated/core.ts` and `generated/cart.ts` are generated by `openapi-typescript` from the pinned
`@shop/api-contract` package. Never edit them by hand; CI runs `make check-api` and fails on drift.

## Bump the contract

1. Change the tarball URL of `@shop/api-contract` in `package.json` to the new
   `contract-v<version>` release.
2. `pnpm install`
3. `pnpm gen:api`
4. Commit `package.json`, `pnpm-lock.yaml` and the generated files.
