# API types

`generated/core.ts` and `generated/cart.ts` are generated by `openapi-typescript` from the
self-contained bundles `node_modules/@shop/api-contract/dist/core.yaml` and `dist/cart.yaml` of the
pinned `@shop/api-contract` package. Never edit them by hand; CI runs `make check-api`, which
regenerates them and fails when the result differs from the commit.

## Bump the contract

1. Change the tarball URL of `@shop/api-contract` in `package.json` to the new
   `contract-v<version>` release (`.../contract-v<version>/shop-api-contract-<version>.tgz`).
2. `pnpm install`
3. `pnpm gen:api` (reads `dist/core.yaml` and `dist/cart.yaml`; the generated headers name the version)
4. `make lint test`. Fix type breaks in app code, never in `generated/`.
5. Add a Vietnamese message in `error-messages.ts` for every new code in the catalogue
   (`openapi/errors.yaml`); the coverage test in `error-messages.test.ts` fails until you do.
6. Commit `package.json`, `pnpm-lock.yaml`, the generated files and the app fixes together.
